# NO GUESTLIST – Europe Tour

Tour page for NO GUESTLIST (Rammie & Nai). Live at https://4amramen.github.io/noguestlist/

## Add or change a ticket link
1. Open `index.html` on GitHub and click the pencil (Edit).
2. Find `const SHOWS = [` near the bottom.
3. Paste the link between the quotes after `tickets:` for that city, e.g.
   `tickets: "https://example.com/your-event"`
4. Click **Commit changes**. The site updates in about a minute.

An empty `tickets: ""` shows "Tickets soon". Shows switch to "Played" the day after their date.
